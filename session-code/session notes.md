Patterns for embedding FinOps into cloud architectural decisions
 
“Every architectural decision carries a cost implication, yet cost is typically discovered in monthly bills rather than design reviews. In this code talk, we demonstrate how to shift FinOps left, optimizing before you deploy rather than reacting after. Through two personas, a FinOps engineer and a builder, you will see live how to embed cost governance into infrastructure-as-code, tackle real architectural trade-offs then show how AI coding assistants accelerate this at scale. You will leave with deployable CloudFormation examples and a mental model for choosing the right cost governance level for your organization.”
